# L3ARN VISUAL REFERENCES

## Purpose

This folder is the visual-quality reference area for the child-facing Academy.

The final target is:

**Premium stylized-realism first-person 3D educational adventure.**

References establish the bar for:
- first-person presence
- world scale
- lighting
- fog/atmosphere
- animation
- responsiveness
- game-native HUD
- environmental interaction
- mission presentation
- premium interactive visualization

They are not instructions to copy one exact game's art style.

The visual implementation specification was derived from:

## Reference families captured in the analysis

- Alexandria-style first-person educational walkthrough:
  - full-screen world
  - diegetic signage
  - minimal HUD
  - AI narration/transcript
- Pelagic-style atmosphere:
  - fog hue as zone identity
  - cinematic depth
- Orbis-style premium interactive visualization:
  - restrained typography
  - polished interactive objects
- MegaBonk-style readability/game feel:
  - strong silhouettes
  - clear HUD
  - live world behind overlays
  - satisfying feedback
- Whisperwood-style exploration:
  - simple readable movement
  - dappled environmental lighting

## Directory convention

`current-bad/`
- screenshots of the current/old child experience
- anti-references
- never preserve a layout merely because it exists

`target/`
- selected quality/game-feel reference frames
- use for comparison during browser QA

`qa/`
- implementation screenshots/videos produced during tasks

## Non-negotiable interpretation

Do not interpret “stylized” as:
- cheap
- flat
- primitive forever
- preschool-looking

Do not interpret “first-person” as:
- military
- violent
- twitch-skill dependent

We want the immersion, movement, environmental interaction, animation quality, and full-screen presence of a polished first-person game applied to a safe educational adventure.
